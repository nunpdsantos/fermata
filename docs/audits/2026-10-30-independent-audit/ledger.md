# Fermata audit: master ledger

Merged from seven auditor tracks (A-G, Opus), the main session's live walkthrough (U), and independent verifiers (Sonnet) who re-checked every S1/S2 finding. Built per `merge-spec.md`. Repo state audited: `228f541` (live site identical, per Track F).

**How to read it.** Severity is the unified rubric in `merge-spec.md`, not the tracks' own ratings: S1 Critical, S2 Serious, S3 Minor. Where a verifier corrected a count, scope or severity, the corrected figure is used and the change is noted under the row's *Verified* entry. *Verified* values: **confirmed** = an independent verifier re-checked it and it stands; **partial** = it stands with corrections; **live** = observed in the running app, mostly in the main session's walkthrough of a production build (for merged rows, the verifier result is in the note); **not re-checked** = mostly S3 items no one re-checked. Sources ending *-IMP-n* are items from a track's improvement list; *verify-X extra n* are extra issues a verifier found.
